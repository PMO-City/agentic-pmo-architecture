# Contributing

Thank you for helping improve the public Agentic PMO reference architecture.

## Good contributions

Useful contributions include:

- identifying ambiguous or conflicting wording;
- suggesting a clearer explanation for a defined audience;
- proposing a concrete example;
- improving diagrams, accessibility, or navigation;
- correcting a factual or editorial error; and
- asking how a claim could be evidenced or tested.

## Before opening a pull request

Please check that your change:

- stays within the public scope;
- does not include private source material or credentials;
- distinguishes aspiration from evidence;
- preserves the nine-step loop and canonical boundaries;
- uses PMO City naming consistently; and
- explains any change that could affect meaning.

## Review path

Open an issue for a question or challenge. Open a pull request for a proposed correction or addition. Changes to architecture meaning require architecture-owner review; editorial changes require editorial review. Merging a pull request does not claim that a product conforms to the architecture.

## Working locally

The repository is Markdown-first. Keep public pages readable in GitHub's renderer and avoid dependencies that make the content difficult to reuse. If you add generated material, include the source and the reproduction instructions.
