# Agentic PMO public architecture v1.0.1

**Release status:** Canonical public release<br>
**Steward:** PMO City<br>
**Public release type:** License and governance patch

## What changed

Version 1.0.1 establishes the repository as PMO City's maintained canonical
public edition. It adds the CC BY 4.0 license, public security guidance,
review scaffolding, and explicit public-source governance.

The public content model remains the v1.0 reading edition: definition,
nine-step operating model, canonical concepts, human–AI governance, worked
example, conformance guide, and glossary.

## What remains outside scope

This release does not publish:

- private implementation details;
- exhaustive internal requirements;
- private architecture decisions or review records;
- product certification; or
- a claim that the Agentic PMO is an independently governed industry standard.
