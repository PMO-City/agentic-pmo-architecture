# Agentic PMO public architecture v1.0

**Release status:** Public review release<br>
**Steward:** PMO City<br>
**Internal source baseline:** PMO City Architecture v1.2.1<br>
**Public release type:** Curated explanatory edition

## What this release provides

Version 1.0 is the first public reading edition of the Agentic PMO reference architecture. It presents the category in a form that a leader, architect, or builder can understand without reading the internal architecture manuscript.

It includes:

- a concise category definition;
- the nine-step operating loop;
- the canonical model and its most important distinctions;
- human–AI governance boundaries;
- one end-to-end worked example;
- a practical conformance boundary; and
- a glossary and publication contract.

## What this release does not provide

It does not publish:

- the internal chapter corpus;
- the complete numbered requirements set;
- private implementation details;
- private architecture decisions or review records;
- product certification; or
- a claim that the Agentic PMO is an independently governed industry standard.

## Known limitations

- The public edition is explanatory and does not independently own normative meaning.
- The examples are illustrative, not universal implementation prescriptions.
- The documentation and example-asset license remains to be selected explicitly.
- A future release should add additional domain examples and implementation profiles.

## Release integrity

The public release is maintained as a tagged Git commit. Changes after the tag belong to a later release or an explicitly documented correction. The internal source version and public version are recorded separately so that neither version silently replaces the other.
