# Security

This repository contains PMO City's public architecture documentation and
illustrative examples. It should not contain credentials, private source
material, customer information, or deployment secrets.

## Reporting a security problem

Please do not disclose suspected secrets, account compromise, or other
security-sensitive issues in a public issue.

Send a private report to `contact@pmo.city` with:

- a short description of the issue;
- the affected file, URL, or repository setting;
- steps to reproduce where relevant; and
- any evidence needed to assess the report.

If the report concerns a GitHub account, organization setting, credential, or
deployment system, do not include the secret itself. Identify where it may
have been exposed and rotate it through the responsible system.

PMO City will acknowledge reports when practical, investigate them, and
coordinate any necessary correction or disclosure. Please allow time for
assessment before publishing details of a suspected issue.

## Safe contribution rules

Contributors must not commit:

- API keys, passwords, tokens, private keys, or session material;
- private architecture documents or private repository URLs;
- personal, customer, or confidential organizational data; or
- unreviewed claims of certification, compliance, or conformance.

When in doubt, open a general issue asking for guidance rather than including
sensitive material in a pull request.
